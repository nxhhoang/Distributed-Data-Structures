# 112 — Remove the Vowels from a String

## Problem
Filter out all vowels (a, e, i, o, u).

## Input
`argv[1]`: string.

## Output
```
vowels removed: "<result>"
```

## Example
```
mpirun -np 4 ./bin 112_remove_vowels "beautiful day"
vowels removed: "btfl dy"
```

## Solutions
- `v1_basic` — filter.
